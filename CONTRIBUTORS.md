## Attribution notes

- OpenAI GPT is an AI assistant, not a human GitHub account or an independently accountable project maintainer.

- This attribution does not imply that OpenAI sponsors, endorses, owns, or officially maintains Veltrunix.
- GitHub's automatic Contributors graph is based on commit authorship and qualifying repository history; this document is a project-maintained acknowledgment and does not add an OpenAI account to that graph.
